# COMP177 Final Project

An interactive visualization project for COMP177. Topic, audience, and dataset are to be selected.

## Project structure

```text
.
├── index.html              # Web app entry point
├── src/
│   ├── css/styles.css      # App styles
│   └── js/
│       ├── main.js         # App initialization
│       └── components/     # Visualization components
├── assets/images/         # Images and other visual assets
├── data/
│   ├── raw/               # Original source data
│   └── processed/         # Browser-ready data
├── scripts/               # Reproducible data preparation
├── docs/
│   └── design/            # Sketches and interaction designs
├── submission/
│   └── video/             # Video script and recording notes
├── FinalProject.pdf       # Assignment requirements
└── plan.md                # Milestones and deliverable checklist
```

## Run locally

From the project root, run:

```sh
python3 -m http.server 8000
```

Open http://localhost:8000. No build step or dependencies are required for this starter.
